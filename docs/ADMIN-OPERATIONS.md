# VAC Content Management Guide

This guide is for authorized VAC committee members maintaining the site's public information.

## Everyday updates

Sign in using the official VAC administrator login with your personal authorized account. Keep credentials private and never reuse passwords.

The dashboard manages:
- Committee roles, profile photos and public-facing details
- Announcements and event banners
- Event schedules and countdowns
- Gallery photographs and video thumbnails linked to original VAC Facebook posts
- Membership applications and the club's member registry

Before publishing, check names, dates, image crop, mobile layout and linked destination URLs. Upload images that VAC is entitled to publish, and seek permission before showing a person's private details publicly.

## Membership workflow

Applications are submitted through the official Join VAC form. Payment verification is a **manual administrative decision**; a generated PDF receipt is not evidence of verified payment or approved membership.

Handle application records only through the authorized admin interface. Do not copy student IDs, payment transaction IDs, phone numbers or application PDFs into public spreadsheets, GitHub issues or screenshots.

## Continuity

When a committee changes, review public details, archive the old event materials appropriately, transfer legitimate access securely and remove old access rights. Prefer using the dashboard rather than editing code for routine club content changes.

For deployment or account-access issues, contact the technical maintainer privately. Production credentials and internal runbooks must be stored outside this public repository.
